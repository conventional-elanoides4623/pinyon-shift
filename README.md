## 🛠️ Troubleshooting & FAQ

We want your experience to be hassle-free. Here are answers to common questions and solutions to potential issues.

### ❓ The Game Won't Start

*   **Check Antivirus:** Sometimes, antivirus software flags new game executables. Add an exception for the folder where you extracted pinyon-shift.
*   **Run as Administrator:** Right-click on `pinyon-shift.exe` and select **"Run as administrator"**. This can resolve permission issues.
*   **Update Graphics Drivers:** Make sure your GPU drivers are up to date. Visit the website of your graphics card manufacturer (NVIDIA, AMD, or Intel) to get the latest drivers.

### ❓ The Game is Laggy or Slow

*   **Lower Graphics Settings:** In the game's options menu, reduce the resolution and turn off effects like shadows and anti-aliasing.
*   **Close Background Programs:** Close any unnecessary applications (browsers, streaming software) to free up system resources.
*   **Check Your Hardware:** Ensure your PC meets the minimum system requirements listed above.

### ❓ I See a "Missing DLL" Error

*   **Install Visual C++ Redistributables:** Download and install the latest Visual C++ Redistributable package from Microsoft's website. This is a common requirement for games built with C++.
*   **Re-extract the Files:** The zip file might have been corrupted during download. Delete it, download again, and re-extract.

### ❓ How Do I Save My Progress?

*   The game automatically saves your progress at key points, such as after completing a race or buying a car. You don't need to manually save. Just exit the game normally, and your progress will be there next time you launch.
